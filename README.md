# Dingtone Clone App

مشروع Android تجريبي يقدّم واجهة تسجيل دخول وشاشة رئيسية مشابهة لفكرة تطبيقات الاتصال المجاني مثل Dingtone، مع تصميم عربي/إنجليزي جاهز للتوسعة.

## المتطلبات
- Android Studio Iguana أو أحدث
- JDK 17
- Android SDK

## التشغيل
1. افتح المشروع في Android Studio.
2. Sync Project with Gradle Files.
3. شغّل التطبيق على محاكي أو جهاز فعلي.

## المميزات الحالية
- شاشة تسجيل دخول
- شاشة رئيسية للتطبيق
- شريط تنقل أسفل الشاشة
- بطاقات المكالمات، جهات الاتصال، الرسائل
- دعم عربي + تصميم نظيف

## ملاحظات
هذا المشروع هو نسخة starter للتجربة السريعة، ويُستخدم كأساس للتطوير المستقبلي مع:
- تسجيل دخول حقيقي
- قاعدة بيانات
- مكالمات VoIP
- رسائل/دردشة
- إدارة اشتراكات
- اتصال مع backend
